# 验收标准（monitor-api-operations）

## 功能验收

| 步骤 | 验收标准 |
|------|---------|
| 查看调用汇总 | 返回成功，含总调用次数、成功率、平均耗时 |
| 分析调用趋势 | 返回成功，含时间维度调用量数据 |
| 查看调用日志 | 返回成功，含调用明细记录 |
| 异常影响分析 | 返回成功，含异常影响汇总或明细 |

## 非功能验收

- [ ] SKILL.md 行数 ≤ 500
- [ ] 所有 CLI 命令含 --user-agent
- [ ] 无写操作，无需 HITL 确认
- [ ] 大整数 ID 用字符串格式
- [ ] session-id 继承自父层
