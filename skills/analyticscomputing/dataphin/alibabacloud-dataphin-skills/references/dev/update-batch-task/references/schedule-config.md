# 调度配置补充说明

## 分钟级调度的两种语义

| 语义 | 说明 | CronExpression | CustomScheduleConfig |
|---|---|---|---|
| **每小时重置** | 每个整点起按间隔触发，下一小时重置 | `0 0/05 0-23 * * ?` | `null` 或不传 |
| **全天连续** | 从 00:00 开始连续按间隔触发，跨小时不重置 | `0 0 0 * * ?` | 必填 |

> 第二种语义下，即使 CronExpression 写成 `0 0/05 0-23 * * ?` 在 5 分钟场景看起来一样，但系统内部按 CustomScheduleConfig 解析。若换成 7 分钟，区别会显现：全天连续期望 `00:07, 00:14, ..., 01:03, 01:10`；每小时重置则期望 `00:07, 00:14, ..., 00:56, 01:07`。

## 全天连续间隔调度示例（每 5 分钟）

```jsonc
{
  "SchedulePeriod": "MINUTELY",
  "CronExpression": "0 0 0 * * ?",
  "CustomScheduleConfig": {
    "SchedulePeriod": "DAY",
    "Interval": 5,
    "IntervalUnit": "MINUTE",
    "StartTime": "00:00",
    "EndTime": "23:59"
  }
}
```

## 多时点 cron（小时级）

- 分钟相同时用单 cron 多钟头：`0 45 8,20 * * ?`（08:45、20:45）
- 分钟不同时用 `|` 分隔：`0 23 1 * * ?|0 33 19 * * ?`（01:23、19:33）
- ❌ 避免笛卡尔积：`0 23,33 1,19 * * ?` 会展开成 01:23/01:33/19:23/19:33 共 4 个时点
