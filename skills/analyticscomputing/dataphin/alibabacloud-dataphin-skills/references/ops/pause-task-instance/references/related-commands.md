# 相关命令

> 本 skill 涉及的 `aliyun dataphin-public` 命令清单。

| 命令 | 用途 |
|------|------|
| `aliyun dataphin-public --help` | 查看全部命令 |
| `aliyun dataphin-public list-projects` | 枚举项目 |
| `aliyun dataphin-public list-instances` | 按任务名/节点/业务日期查询实例，输出 DueTime |
| `aliyun dataphin-public operate-instance` | 批量运维实例：PAUSE / RESUME / RERUN / TERMINATE / SET_SUCCESS |
| `aliyun dataphin-public get-physical-instance` | 查询单个实例信息（含 `NodeInfo.SchedulePaused`） |
