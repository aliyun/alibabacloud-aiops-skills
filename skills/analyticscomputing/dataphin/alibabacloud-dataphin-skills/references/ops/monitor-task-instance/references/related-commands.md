# 相关命令

> 本 skill 涉及的 `aliyun dataphin-public` 命令清单。

| 命令 | 用途 |
|------|------|
| `aliyun dataphin-public list-instances` | 按任务名 + 业务日期查询实例列表 |
| `aliyun dataphin-public get-physical-instance` | 查询单个实例详情与状态 |
| `aliyun dataphin-public get-physical-instance-log` | 查询实例 taskrun 执行日志 |
| `aliyun dataphin-public list-nodes` | 查询节点元数据（含 SchedulePaused） |
| `aliyun dataphin-public resume-physical-node` | 恢复被暂停的节点 |
| `aliyun dataphin-public --help` | 查看全部命令 |
