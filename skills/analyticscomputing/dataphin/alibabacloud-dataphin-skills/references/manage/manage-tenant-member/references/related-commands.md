# 相关命令

> 本 skill 涉及的 `aliyun dataphin-public` 命令清单。

| 命令 | 用途 |
|------|------|
| `aliyun dataphin-public list-addable-users` | 查询可加入租户但尚未加入的用户 |
| `aliyun dataphin-public add-tenant-members` | 按用户 ID 批量添加租户成员 |
| `aliyun dataphin-public add-tenant-members-by-source-user` | 按来源用户批量添加租户成员 |
| `aliyun dataphin-public list-tenant-members` | 查询当前租户成员列表 |
| `aliyun dataphin-public list-addable-roles` | 查询可配置的全局角色 |
| `aliyun dataphin-public update-tenant-member` | 更新租户成员全局角色 |
| `aliyun dataphin-public remove-tenant-member` | 移除租户成员 |
| `aliyun dataphin-public --help` | 查看全部命令 |
