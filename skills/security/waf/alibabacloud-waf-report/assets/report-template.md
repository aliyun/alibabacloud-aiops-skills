### 附录D：评估方法论要点

**判定"误报"的正确姿势：**

> **公网 curl 401/405 只是最低门槛**。必须结合流量层数据回答：
> 1. 该接口在鉴权后是否被大量正常访问？
> 2. 告警的"内容特征"是否只能在登录后触发？
> 3. 内网场景下是否有风险？
> 4. 有无连锁风险？

**关键洞察**：
1. 状态码 200 ≠ 接口存在（SPA 兜底页）
2. API 安全模块无法区分业务鉴权
3. 不同检测模块不能用固定优先级替代证据验证
4. 合法第三方回调容易被误判
5. 数据保留时间限制排查深度
