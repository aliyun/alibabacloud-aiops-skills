## 1. Metering Units and Unit Prices

| Metering Unit | Unit Price | Description |
| --- | --- | --- |
| **SeCU** | 0.05 CNY / SeCU | Unified metering unit for WAF 3.0 pay-as-you-go |
| **Credit** | 100 Credit = 1 CNY | Dedicated metering unit for the Agentic API Security module |

Cost conversion:
```
Cost(CNY) = Cu × 0.05 + Credit × 0.01
```

> Except for the WAF instance fee, SeCU is counted per full hour and rounded up. The WAF instance fee is billed at the actual rate of 0.5 SeCU/hour.

| `BillDetail[].CreditChargeData` | string | Credit usage details as a JSON string |

## 3. ChargeData Field Mapping

`ChargeData` is a JSON string. The parsed fields are described below.

### Instance Related

| Field | Console Display | Description |
| --- | --- | --- |
| `instanceFee` | WAF Instance | WAF pay-as-you-go instance base fee, 0.5 SeCU/hour |

### Traffic Processing Related

| Field | Console Display | Description |
| --- | --- | --- |
| `request` | Basic Traffic Fee | Number of business requests, 1 SeCU / 5,000 requests/hour |
| `qps` | QPS Peak | QPS peak exceeding 1,000, 1 SeCU / 5 QPS/hour |
| `apisecTraffic` | API Security: Request Processing Fee | API security traffic |
| `botTraffic` | Bot Management: Request Processing Fee | Bot management traffic |
| `riskTraffic` | Bot Management: Risk Identification | Risk identification hit count |
| `customAclCaptcha` | Custom Rule: Slider Action | Slider challenge invocations |

| `gslb` | Intelligent Load Balancing | Whether intelligent load balancing is enabled |
