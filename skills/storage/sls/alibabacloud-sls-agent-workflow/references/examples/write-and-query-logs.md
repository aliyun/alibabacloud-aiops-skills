# Example: write and query logs

Goal: write sample application logs to SLS and query them to calculate error counts and average latency.

Reuse existing resources where available. The steps describe the sequence; use CLI help and the selected skills for operation details.

1. **Prepare sample logs.** For example, use the following JSON logs with a service name, HTTP status code, and request latency in milliseconds:

   ```jsonl
   {"request_id":"r1","service":"checkout","status":200,"latency_ms":20}
   {"request_id":"r2","service":"checkout","status":500,"latency_ms":120}
   {"request_id":"r3","service":"checkout","status":503,"latency_ms":160}
   ```

2. **Prepare the destination.** Choose the region, Project, and Logstore. If needed, use `aliyun sls create-project` and `aliyun sls create-log-store` to create the resources.
3. **Configure indexes.** Use `alibabacloud-sls-index-config-management` to create or update the Logstore's index configuration based on the sample logs and intended queries. Let the configuration take effect before writing the sample; index changes apply only to subsequent new logs.
4. **Write the sample logs.** Use `aliyun sls put-json-logs` to write the samples to the target Logstore.
5. **Query and analyze.** Use `alibabacloud-sls-query` to query the samples over a time range that includes the writes — the range is a request-level setting (for example, from a few minutes before writing to now), not a clause inside the SQL. Calculate error counts and average latency, and check the results against the sample logs.  The SQL generated by alibabacloud-sls-query might look like this:

   ```sql
   service:checkout |
   SELECT count(*) AS requests,
          sum(CASE WHEN status >= 500 THEN 1 ELSE 0 END) AS errors,
          avg(latency_ms) AS avg_latency_ms
   FROM log
   ```
