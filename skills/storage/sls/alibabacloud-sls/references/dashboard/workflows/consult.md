# Explain and review configuration

The [reference index](../index.md) links settings to their effects, fields and
examples. A single-setting explanation can use the corresponding parameter page.

For data-related questions, the configuration connects queries through
[transformations](../features/transformations.md) to [chart bindings](../model/result-shapes.md).
[Time](../queries/time-and-limits.md) and [variables](../features/variables.md) describe
how the selected window and controls affect those results.

Local JSON and query results provide configuration context. CLI reads can supply
missing source information; [validation tools](../validation/checks.md) can check
configuration types and relationships.
