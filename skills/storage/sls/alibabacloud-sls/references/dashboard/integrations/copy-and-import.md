# Copy, import, and export

The JSON response from a [dashboard read](../workflows/publish.md#existing-configuration) can be exported or copied.

The destination account, region, Project and dashboard ID select where a copy is
saved. Query sources remain separate fields in the configuration. A copy includes
chart settings and queries; data, indexes and access permissions belong to the
referenced resources.

[Publishing](../workflows/publish.md) provides create and update commands.
[Validation tools](../validation/checks.md) can check configuration and relationships.
The [official import/export guide](https://help.aliyun.com/zh/sls/import-and-export-sls-dashboards)
covers the console workflow.
