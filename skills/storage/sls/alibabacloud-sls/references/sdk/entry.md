# SDK integration

When the SDK is already identified, its directory under [SDK references](sdks/) contains
installation and operation examples. For selection or comparison, use the
[capability matrix](route.md#sdk-capability-matrix) and [selection guidance](route.md#selection-rules).

## Scenarios

| Need | Reference |
| --- | --- |
| Install dependencies | [Installation](scenarios/install.md) |
| Write logs or integrate a logging framework | [Writing](scenarios/write-logs.md) |
| Consume logs or use cursor-based reads | [Consumption](scenarios/consume-logs.md) |
| Query or analyze logs | [Queries](scenarios/query-logs.md) |
| Manage SLS resources through an SDK | [Resource-management SDK selection](route.md#selection-rules) |

The guides can be combined for tasks spanning several operations.
Version-sensitive examples can use package-manager resolution or Maven/Gradle version
placeholders rather than inventing a latest version.
