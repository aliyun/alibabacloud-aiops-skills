# Common appearance

For styling edits, read the chart reference and the relevant shared settings:

- [Basic options](basic-options.md): titles, borders, backgrounds and fixed time.
- [Standard options](standard-options.md): formatting, units, decimals and colors.
- [Legend](legend.md) and [Tooltip](tooltip.md).
- [Thresholds](thresholds.md) and [value mapping](value-mapping.md).
- [Field overrides](field-overrides.md) for one query field.

Preserve queries, datasource identities and unrelated styling. Shared settings
apply only to charts that support them.

For line/point styling and axis ranges, see [line and axis options](xy-options.md).
For functions that reduce a series to one value, see [reducers](reducers.md).
