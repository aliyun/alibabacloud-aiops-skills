# Consult and review

Classify the intended effect: querying, result transformation, presentation,
controls, navigation or integration. Select references from the
[knowledge index](../index.md). Start with the visible setting and its location,
then explain its effect, scope, prerequisites and limits.

For a configuration review, trace queries through
[transformations](../features/transformations.md) to [result
bindings](../model/result-shapes.md); include time and variables when they affect the
result. Distinguish confirmed errors from hypotheses requiring live data. Use linked
product documentation for details not covered by the references.

Answer locally when possible; use read-only cloud lookups only for missing data.
[Sharing](../integrations/sharing-and-embedding.md) remains advisory. Subscription
operations use the separate [Report Job workflow](../integrations/subscriptions.md).
