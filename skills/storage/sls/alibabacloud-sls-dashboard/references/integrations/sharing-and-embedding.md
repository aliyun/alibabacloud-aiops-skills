# Sharing and embedding

Use the SLS console to create and manage shares; this skill provides configuration
guidance. Identify the Region, Project, dashboard and intended audience before
creating a share.

## Access channels

- Unrestricted URL: recipients open the link directly without an account restriction.
- Alibaba Cloud account: restrict access to the configured account IDs.
- DingTalk account or WeCom account: bind the Alibaba Cloud main account and the
  RAM user creating the share to the target organization. Its administrator must
  enable the SLS sharing application.

## Shared view

Set the link's validity to a specified expiration date or long-term access.
Validity controls when the link can be opened, not the query's data time range.
Lock the time range to prevent recipients from changing it. Retain filters and
variables to carry the selected filters and query parameters into the shared view.

Password-free sharing supports external views and embedding. Use console embedding
for integrating SLS pages into an application; embedding does not remove access
restrictions.

Sharing permissions include `log:CreateDashboardSharing`, `log:AccessDashboardSharing`,
`log:DeleteDashboardSharing`, `log:UpdateDashboardSharing` and `log:ListDashboardSharing`.
Use the share link generated by the console.
